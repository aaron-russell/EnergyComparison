# Versions

The published handbook is built from the same commit as the application. The navigation version is
the `package.json` version, currently **v0.1.0**.

When a breaking contract or workflow change is released, update the version and add a short entry here.
Keep older versioned documentation available when a release needs long-term support; otherwise the
current handbook is the source of truth for the current branch.

## v0.1.0

- Initial documented Energy Replay application and adapter contracts.
- Synthetic energy and charger integrations are the executable examples.
